# Will Selviz — Nike Project Universe

An interactive Three.js timeline of nine Nike campaigns spanning CGI, 3D
animation, VFX, AR, FOOH, and creative technology.

## Live site

[wselviz.github.io/will-selviz-nike-universe](https://wselviz.github.io/will-selviz-nike-universe/)

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

GitHub Pages deploys automatically from `main`.
